## 구현에 반영하는 해석

1. 미션 표지판을 한 번 마주친 상황에 안정적인 추적 ID를 부여하고, 여러 프레임 검출돼도 한 번만 실행한다.
   다음 바퀴의 재접근은 별도 encounter로 처리한다. 반복 주행 채점 방식은 별도 확인 대상이다.
2. 안쪽 횡단보도 네 곳만 미션 대상으로 표시한다. 바깥 횡단보도는 도로 표면 렌더링에서 유지한다.
3. 정지 1초는 제어 명령을 보낸 시간부터가 아니라 **실제로 멈춘 뒤**부터 계산하도록 상태기계를 구현했다.
4. STOP의 정지 시간, 감속률·해제 시점, 경적 길이, 노란 신호 규칙은 확정하지 않았다.
5. “이 위치”, “여기” 같은 시연 표현을 사진 한 장의 특정 파란 원에 임의로 연결하지 않는다.
   기본 시뮬레이션 소품 배치는 예제이며 실제 미션 배치의 복원이 아니다.
